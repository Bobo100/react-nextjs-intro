# React-Next.js-Introduce

Next.js 的教學筆記網站，用實際可執行的頁面說明 Next.js 幫你做了什麼、各種渲染模式，以及路由、圖片、樣式與 API 的用法。

## 狀態

2023 年的練習作品，已不再加新內容，目前沒有線上 demo。

## 內容

| 章節 | 主題 |
|---|---|
| Next.js 做了什麼 | Compiling、Minifying、Bundling、Code Splitting、Pre-rendering |
| 渲染模式 | CSR、SSR、SSG、ISR 的差別與 build 時的行為 |
| 樣式 | CSS-in-JS(含 styled-components)、CSS Modules、套用順序 |
| 自動化的路由 | 檔案路由、動態路由 |
| 圖片 | `next/image` 的本機與遠端圖片 |
| API | API Routes、Dynamic API Routes、Response Helpers、Edge API Routes |

另有 `[locale]` 路由的 i18n 範例(`en-us`、`zh-tw`)。

## 本機執行

```bash
npm install
npm run dev   # http://localhost:3000
```
